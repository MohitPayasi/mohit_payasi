# 🤖 Machine Learning Track

Practical implementations, exploratory data analysis, and mathematical foundations of Machine Learning algorithms using Python, NumPy, Pandas, Scikit-Learn, and Seaborn.

---

## 📚 Curriculum & Notebook Index

| Class | Notebook | Core Topics Covered | Key Libraries |
| :--- | :--- | :--- | :--- |
| **Class 02** | [`class_2.ipynb`](./class_2.ipynb) | **Descriptive Statistics**: Mean, median, mode, variance, standard deviation, student dataset creation & summary metrics. | `numpy`, `pandas`, `statistics` |
| **Class 03** | [`class_3.ipynb`](./class_3.ipynb) | **Exploratory Data Analysis (EDA)**: Multi-feature correlation, distributions, data frames, and Seaborn visual relationships. | `pandas`, `seaborn`, `matplotlib` |
| **Class 04** | [`class_4.ipynb`](./class_4.ipynb) | **Feature Engineering & Encoding**: Categorical preprocessing using `LabelEncoder`, one-hot encoding, and feature inspection on the Tips dataset. | `pandas`, `seaborn`, `scikit-learn` |
| **Class 05** | [`class_5.ipynb`](./class_5.ipynb) | **Outlier Analysis & Data Cleaning**: Detecting and handling anomalies using Boxplots, Z-scores, and IQR filtering. | `numpy`, `scipy.stats`, `matplotlib` |
| **Class 06** | [`class_6.ipynb`](./class_6.ipynb) | **Simple Linear Regression**: Univariate regression model, array reshaping (`reshape(-1, 1)`), line fitting, and basic predictions. | `scikit-learn`, `matplotlib`, `numpy` |
| **Class 07** | [`class_7.ipynb`](./class_7.ipynb) | **Multiple Linear Regression & Evaluation**: Multi-variable regression ($x_1, x_2 \to y$), train-test splitting, coefficients, intercept, and error metrics ($R^2$, MSE). | `scikit-learn`, `pandas`, `numpy` |

---

## 🛠️ Setup & Prerequisites

Make sure the required data science packages are installed:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn scipy jupyter
```

Launch Jupyter Notebook:
```bash
jupyter notebook
```
